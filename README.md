# Crafted Customs - Custom Framing Landing Page

A modern, fully responsive landing page for a custom picture framing business, "Crafted Customs." This project features a dark, premium aesthetic with vibrant pink and rose gold accents, smooth scrolling animations, and a user-friendly mobile navigation system.

## 🚀 Features

* **Responsive Design:** Fully optimized for desktop, tablet, and mobile viewing using modern CSS Grid and Flexbox.
* **Interactive Mobile Menu:** A custom-built hamburger navigation menu that slides in cleanly on smaller screens.
* **Scroll Animations:** Elements elegantly fade and slide into view as the user scrolls, powered by the JavaScript `IntersectionObserver` API.
* **Modern UI/UX:** A split-screen hero section, hover effects, and a cohesive dark-theme color palette (`#0a0a0a` background with `#E8437F` and `#DCAE96` accents).
* **Actionable Contact Links:** Integrated `tel:` and `mailto:` links allowing users to call or email directly from the page.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom properties (variables), media queries, transitions, and modern layouts (Flexbox/Grid).
* **JavaScript (Vanilla):** DOM manipulation, event listeners for the mobile menu, and scroll-triggered animations.
* **Google Fonts:** Playfair Display (headings) and Poppins (body text).
